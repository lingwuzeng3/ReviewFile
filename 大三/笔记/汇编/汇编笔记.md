# Assembly Language (8086)汇编
## 通用寄存器介绍

- `ax`, `bx`, `cx`, `dx` 为4个通用性寄存器，它们用来存储一般性数据，字长为16 位
- 每一个通用寄存器都可以拆分成`xh`, `xl`两个8位的寄存使用 ($x \in (a, b, c, d)$ )
> 注意 在指令执行的过程中，cpu会把 xh xl 看出两个独立的寄存器，所以 如果xl 产生了进位，是不会存到 xh 中的
- 在进行数据传送或运算时，cpu不会对数值进行截断 或者 扩展，所以两个操作对象的位数应当是一致的
    ```asm
    mov ax, bl ; ax: 16bits, bl: 8bits
    mov ah, ax ;
    mov al, 100H ;  100H : 12bits
    
    ```

# stack

## The Pentium stack implementation characteristics
- Only store word or doubleword, never a byte
- stack goes downward, from high address to low address
    - for example, if we allocated 100H (256) byte memory 
    , after push 21ABH, sp now points to 254

    | id   | content | sp pointer |
    |------|---------|------------|
    | 256 |  21    |        |
    | 254 |  AB   | <--sp       |

- Top of stack always points to the last data item  placed on
the stack

> You may wonder, where sp points at the stage of initilaizion, when
> there is no data in the stack <br>
> <font color='red'> the answear is: the byte just outside the reserverd area</font> 

## some basic operation about a stack

| instruction   | function                           |
|---------------|------------------------------------|
| push source16 | SP := SP - 2,  (SS:SP) := source16 |
| pop dst16     | dst16 := (SS:SP), SP := SP - 2     |
| pushf         | save all flag registers            |
| popf          | restore all registers              |
| pusha         | save general purpose register      |
| popa          | restore  <br> ax cx dx bx bp si di |

# proecedure calls
- to define a procedure, we use
```asm
pro-name PROC NEAR
pro-name PROC FAR
```

- to end a procedure, we use
```asm
ENDP pro-name
```

The **near** indicates that calling and called procedures 
are both located in the same segment, otherWise, it is **far** .

- to call a procedure, we use
```asm
call proc-name
```
The call actually do the following things
1. save IP address to the stack
2. change IP to the address specified (IP := IP + relative displacement)

- to return from a procedure, we us
```asm
ret
ret optimal-number
```
The ret instruction actually do the following things
1. restore IP address, IP := [sp], sp:= sp+2
2. the optimal-number means the extra offset for sp, which is use to restore stack 

    sp := sp + 2 + optimal-number
